Security Invariants & Guarantees

check

Zero Static Access Keys

No long-lived AWS IAM secret keys, GCP service account JSON credentials, or GitHub tokens are stored in environment variables.

check

JWKS Cryptographic Verification

Continuous runtime signature validation using public key sets directly fetched from identity provider endpoints over TLS 1.3.

check

Audience (aud) Claim Pinning

Strict audience pinning prevents cross-tenant and confused deputy token replay vulnerabilities across multi-cloud clusters.

check

Sub-second Revocation

Upon runner process termination or pipeline completion, ephemeral leased access tokens are immediately purged in enclave memory.
