# SecretVault — Frontend Application

## Overview
The SecretVault Web Dashboard is built to provide an Apple/Linear/Vercel-level polished experience for managing secrets, multi-platform integrations, team access, and security posture.

## Technology Stack (Planned)
- **Framework:** React 18+ with Vite / Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom Glassmorphism tokens
- **Component Library:** shadcn/ui
- **Icons:** Lucide Icons

## Screen Architecture
The UI encompasses **126 distinct screens** designed in Stitch, mapped in [docs/SCREEN_MAP.md](../docs/SCREEN_MAP.md).
