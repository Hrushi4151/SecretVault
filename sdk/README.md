# SecretVault — Client SDKs

## Overview
Lightweight runtime client SDKs for fetching, caching, and dynamically rotating secrets in applications.

## Target Languages
- Java (`secretvault-java-sdk`)
- TypeScript / Node.js (`@secretvault/sdk`)
- Python (`secretvault-python`)
- Go (`github.com/secretvault/sdk-go`)

See [docs/SDK.md](../docs/SDK.md) for architecture details.
